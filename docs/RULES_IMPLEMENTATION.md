# Rule implementation coverage

The playable release uses the supplied DOCX summary and original, homogeneous infantry profiles on a flat 44×30-inch battlefield. It does not claim complete official/faction play. The source omits the full Rules Appendix, official mission packs and authorized faction data; unsupported unit types are unavailable rather than represented by invented official profiles.

## Authoritative protocol

Strict Zod actions carry request UUIDs and expected revisions. The engine clones input state, validates identity/ownership/status/phase/eligibility, and only then returns a result. The server serializes commits through transactional revision comparison and unique constraints. Accepted state, events, dice and resulting snapshots are persisted before PostgreSQL notifications broadcast them.

A dice-review checkpoint stores the original action, the already-generated dice tape, accepted decisions and overrides. Resuming deterministically replays only that prefix. Later dice do not exist until the rolling player accepts or rerolls. CP is paid once, and request deduplication prevents a retry paying again. A pending review is stored in the match snapshot and survives browser/API/database reconnection.

Actions cover deployment/reserve/ingress, terrain agreement, command/phase progression, movement/charge commits, attacks/declared volleys, defender allocation, fight movement, stratagems, reaction passing, dice policy/review, effect order and concession. No action permits client-supplied random outcomes or arbitrary official profile imports.

## Completion boundary

The local acceptance scope is the complete original-infantry training loop plus the applicable summary mechanics above. Source-dependent advanced units, official army construction/attachments/transports/flyers, official missions, detailed appendix exceptions and real three-dimensional terrain require additional authorized data and geometry. Those remain documented limitations, not active placeholders. The release is not described as complete official Warhammer coverage.
